# Security Policy

## Supported versions

Security fixes are applied to the current stable release of CreceWeb Lumen Theme.

Users should update to the latest stable version before reporting a security issue.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for suspected security vulnerabilities.

Report security concerns privately to CreceWeb:

**Email:** hola@creceweb.com.ar

Please include, when possible:

- the affected Lumen Theme version;
- the affected WordPress and PHP versions;
- a clear description of the issue;
- reproduction steps or a proof of concept;
- the expected security impact;
- any relevant logs or screenshots that do not contain sensitive credentials.

Do not include passwords, API keys, private customer data or production credentials.

CreceWeb will review the report and determine whether the issue affects the current stable release.

## Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a confirmed vulnerability.
