Fonts
No font binaries are bundled. By default the Theme uses system font stacks and makes no font request. Inter Local is stored in WordPress uploads only after explicit administrator selection. Google Fonts are optional and remote only after explicit administrator selection. The Customizer catalog metadata is a bundled local JSON snapshot and is shown only after the administrator enables it.

Third-party libraries and assets
No third-party JavaScript, CSS, font binaries, images, icon libraries, or executable third-party assets are bundled with this Theme. WordPress core-provided dependencies such as jQuery and Dashicons are referenced through WordPress APIs and are not bundled.
