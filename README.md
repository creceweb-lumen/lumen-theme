# CreceWeb Lumen Theme

**A lightweight WordPress theme focused on performance, flexibility and native WordPress workflows.**

CreceWeb Lumen Theme is the core foundation of the Lumen ecosystem. It provides the presentation layer, layout system, navigation, Gutenberg integration and customization tools used to build professional WordPress websites without turning the theme into a large multipurpose framework.

> **Start lightweight. Add functionality intentionally.**

---

## Features

- responsive layouts;
- flexible header and navigation;
- Gutenberg integration;
- blog and content presentation;
- full-width page and post templates;
- accessibility-focused navigation;
- branding and appearance controls;
- social icon presentation controls;
- submenu styling controls;
- footer layout and density controls;
- compatibility with common WordPress workflows;
- optional integration with the rest of the Lumen ecosystem.

---

## Part of the Lumen ecosystem

CreceWeb Lumen is organized into clear layers:

```text
CreceWeb Lumen
│
├── Lumen Theme
│   └── Core website foundation
│
├── Lumen Lite
│   └── Free practical tools
│
└── Lumen Pro
    └── Optional advanced functionality
```

This repository contains the public stable source for **Lumen Theme**.

Lumen Lite and Lumen Pro are separate products with their own responsibilities.

## Installation

The recommended installation method is through WordPress.org:

[Install CreceWeb Lumen Theme](https://wordpress.org/themes/creceweb-lumen/)

You can also install the stable source manually by placing the theme directory inside:

```text
/wp-content/themes/
```

Then activate **CreceWeb Lumen** from:

```text
Appearance → Themes
```

## Reporting bugs

Please use the repository **Issues** section for reproducible bugs affecting Lumen Theme.

Before opening an issue:

- update to the latest stable Lumen Theme release;
- confirm the issue still occurs with current WordPress;
- include your WordPress and PHP versions;
- provide clear reproduction steps;
- mention whether Lumen Lite or Lumen Pro is active;
- avoid including credentials, private URLs or sensitive information.

Security vulnerabilities should **not** be reported as public issues. See [SECURITY.md](SECURITY.md).
