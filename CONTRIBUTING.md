# Contributing to CreceWeb Lumen Theme

Thank you for your interest in improving CreceWeb Lumen Theme.

This repository tracks the public stable source of the WordPress.org theme. Contributions should remain compatible with the project's lightweight architecture and WordPress.org requirements.

## Before opening a pull request

Please:

1. Search existing issues and pull requests.
2. Test against the latest stable WordPress release.
3. Keep the change focused on one problem.
4. Avoid unrelated refactors.
5. Follow WordPress coding standards.
6. Preserve accessibility and responsive behavior.
7. Do not add unnecessary external dependencies.
8. Do not bundle third-party assets without clear licensing and a strong project need.
9. Do not include private project files, credentials, build archives or internal QA documentation.

## Development principles

Lumen favors:

- small, maintainable changes;
- native WordPress APIs;
- progressive enhancement;
- performance-conscious assets;
- accessibility;
- backward-safe defaults;
- clear separation between Theme, Lite and Pro responsibilities.

The Theme should remain functional without Lumen Lite or Lumen Pro installed.

## Pull requests

A pull request should include:

- a concise summary;
- the problem being solved;
- files changed;
- reproduction or testing steps;
- screenshots for visible UI changes;
- accessibility considerations when relevant.

A contribution may be declined when it conflicts with the project architecture, duplicates plugin functionality, introduces unnecessary complexity, or does not fit the public roadmap.

## Bug reports

Use the repository bug-report form for reproducible problems.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
